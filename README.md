# Akváriumi Halfelismerő

Telepíthető telefonos alkalmazás (PWA). Fotózd le az akváriumi halat, és megtudod:
fajt, méretet, természetet (békés / félagresszív / agresszív), akváriumméretet,
vízparamétereket, társíthatóságot, tenyésztést és hogy hol kapható.

- A felismerést a Google Gemini végzi. Az ingyenes kulcsot itt kérheted: https://aistudio.google.com/apikey
- A kulcsot az alkalmazás csak a saját telefonodon tárolja, és csak a Google-nek küldi el.
- Telepítés: Androidon Chrome → „Telepítés a telefonra” gomb, iPhone-on Safari → Megosztás → Főképernyőhöz adás.
- APK: https://www.pwabuilder.com → az oldal címe → Package for stores → Android.
